Наскрізний проєкт: Вебплатформа RMT для корекції моторних порушень
1. Предметна область та призначення
Вебзастосунок для інтерактивної ритмічної слухової стимуляції (Rhythmic Auditory Stimulation — RMT) у дітей із моторною диспраксією та аутизмом. Мета: надати інструмент для адаптивних фізичних вправ під регульований ритм (BPM) із використанням вебкамери та AI-аналізу рухів у реальному часі (MediaPipe Pose / TensorFlow.js).
2. Передбачувані сутності даних (Python / SQL)
User (Користувач/Пацієнт/Лікар): id (int), username (str), email (str), role (str)
Exercise (Вправа): id (int), title (str), target_bpm (int), video_url (str)
Session (Тренувальна сесія): id (int), user_id (int), exercise_id (int), rhythm_accuracy_score (float), completed_at (datetime)
